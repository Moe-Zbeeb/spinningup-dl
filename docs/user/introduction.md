# Introduction

## What This Is

Welcome to Spinning Up in Deep Learning! This is an educational resource produced by [AUB Frontier AI Fellows](https://aub-faf.com/) (AUB–FAF) at the American University of Beirut. It is meant to make it easier to learn deep learning properly: the ideas, the math behind them, and the code that makes them run.

The resource is organised the way OpenAI's [Spinning Up in Deep RL](https://spinningup.openai.com/) is, because that structure works. When complete it will contain:

- a short [introduction](../intro/dl_intro.md) to the terminology, the kinds of neural networks, and how they are trained,
- an [essay](../resources/researcher.md) about growing into a deep learning research role,
- a [curated list](../resources/keypapers.md) of important papers organised by topic,
- well-documented, standalone implementations of [key models](models.md),
- and a few [exercises](../resources/exercises.md) to serve as warm-ups.

## Why We Built This

AUB Frontier AI Fellows brings undergraduates into small research teams, supervised by AUB faculty and mentored by Lebanese AI researchers from frontier labs, universities, and companies. Students join with very different backgrounds, and the first question is almost always the same: what do I need to learn to contribute?

There are excellent textbooks, courses, and papers on deep learning. What is harder to find is one place that takes you from the first definitions to code you can modify and a sense of how research is actually done. Spinning Up in Deep Learning is our attempt at that place, written for our own fellows and open to everyone.

## How to Use This Resource

If you are new to deep learning, read the three parts of the Introduction to Deep Learning in order, then pick a model from the Models Docs and work through its page with the code open beside it.

If you already train networks and want to move toward research, start with the essay for researchers and the key papers list, and use the model pages as references.

Throughout the pages you will see boxes like this one:

```{admonition} You Should Know
These boxes hold the points worth stopping for: a definition you will need later, a common mistake, or the reason a detail is the way it is.
```

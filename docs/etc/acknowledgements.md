# Acknowledgements

Spinning Up in Deep Learning is inspired by Spinning Up in Deep RL, written by Joshua Achiam at OpenAI, from which it borrows its name, its structure, its teaching approach, and its design.

The course follows the topics of the Deep Learning Specialization by Andrew Ng, offered by DeepLearning.AI on Coursera.

It is also inspired by public notes from Amir Masoud Sefidian, Nathan Lambert, and Andrej Karpathy.

The site is built with Sphinx, the Read the Docs theme, and MyST. Its figures are drawn with Matplotlib, and its code uses PyTorch.
